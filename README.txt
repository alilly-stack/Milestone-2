# Exploring the Cosmos — Milestone 2

## Files
- `index.html` — website structure and astronomy content
- `style.css` — external stylesheet, colors, fonts, layout, and responsive rules

## Run locally
Keep both files in the same folder. Open `index.html` in a web browser. An internet connection is needed for Google Fonts and the remote space photographs.

## Responsive design
The stylesheet includes breakpoints for:
- Mobile: 480px and below (supports 320px)
- Tablet/smaller screens: 768px and below (supports 768px)
- Large desktop: 1200px and above

## GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html` and `style.css` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and copy the live URL into your assignment.

## Before submitting
- Test at 320px, 768px, and 1200px using Chrome DevTools.
- Confirm the page loads without errors.
- Confirm the GitHub Pages URL opens and the navigation links work.
